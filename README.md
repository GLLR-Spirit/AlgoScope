# AlgoScope — Interactive Algorithm Lab

A free static educational website for learning algorithms through interactive visualizations, plain-English explanations, complexity notes, and C examples.

## Guides
- Bubble Sort — comparisons, swaps, and sorted passes.
- Insertion Sort — sorted prefix, key comparisons, and shifts.
- Binary Search — midpoint checks and shrinking search ranges.

## Tech stack
HTML5, CSS3, vanilla JavaScript, GitHub Pages. No build step, package manager, API key, or server is required.

## Run locally
Open `index.html` in a browser, or serve this directory with any static HTTP server.

## Deploy with GitHub Pages
1. Open **Settings → Pages**.
2. Choose **Deploy from a branch**.
3. Select `main` and the `/ (root)` folder, then save.
4. Wait for deployment to complete.

Expected URL: https://gllr-spirit.github.io/AlgoScope/

## SEO
Unique page titles and descriptions, canonical URLs, crawlable HTML content, internal links, `robots.txt`, and `sitemap.xml` are included. Submit the sitemap in Google Search Console after deployment; indexing is not guaranteed.

## Structure
- `index.html` — home page
- `styles.css` — responsive styles
- `script.js` — visualizer logic
- `algorithms/` — individual guide pages
- `robots.txt`, `sitemap.xml` — crawl guidance
