What this first version supports

  • Run JavaScript and read console output and runtime errors.
  • Use a disposable sandboxed iframe; the code does not receive access to the parent page's DOM.
  • Step backward and forward through a built-in Bubble Sort trace with array snapshots and counters.

Important: arbitrary JavaScript is executed, but its internal operations are not automatically traced yet. Python and C support are planned for later stages.
