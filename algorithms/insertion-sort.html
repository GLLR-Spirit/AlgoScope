What is Insertion Sort?

Insertion Sort builds a sorted section from left to right. Each new value is held as a key, larger values shift right, and the key is inserted into the gap.

Color guide

Green: sorted section. Purple: values currently compared. Blue: values not yet inserted.

Complexity

Best timeO(n)
Average timeO(n²)
Worst timeO(n²)
Extra spaceO(1)

How Insertion Sort works

Think of sorting cards in your hand. Keep the left part sorted, take the next card, shift larger cards to make room, and insert the new card into the gap.

  1. Assume the first element is sorted.
  2. Choose the next element as the key.
  3. Shift sorted elements larger than the key one position right.
  4. Insert the key and continue.
Learning tip: watch the sorted section grow by one element each time a key is inserted.

Insertion Sort implementation in C

void insertionSort(int arr[], int n) {
    for (int i = 1; i < n; i++) {
        int key = arr[i];
        int j = i - 1;
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key;
    }
}

Insertion Sort is effective for small arrays and data that is already nearly sorted. It is stable when equal values are not shifted past one another.
