What is Insertion Sort?

Insertion Sort builds a sorted section from left to right. Each new value is held as a key, larger values are shifted right, and the key is inserted into the gap.

How to read the colors

  • Green: the sorted section.
  • Purple: the key and value currently examined.
  • Blue: values not yet inserted.

Complexity

Best timeO(n)
Average timeO(n²)

UNDERSTAND THE ALGORITHM

How Insertion Sort works

Think of sorting cards in your hand. Keep the left part sorted, take the next card, shift larger cards to make room, and insert the new card into the gap.

  1. Assume the first element is already sorted.
  2. Choose the next element as the key.
  3. Shift sorted elements that are greater than the key one position to the right.
  4. Insert the key into the empty position and continue.
Learning tip: watch the green sorted section grow by one element each time a key is inserted.

Insertion Sort implementation in C

void insertionSort(int arr[], int n) {
    for (int i = 1; i < n; i++) {
        int key = arr[i];
        int j = i - 1;
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key;
    }
}

The key is stored separately before shifting begins, so its value is not lost. Insertion Sort is stable when equal values are not shifted past one another.

When should you use Insertion Sort?

It works well for small arrays and data that is already nearly sorted. Its simple implementation also makes it a useful introduction to array manipulation and loop invariants.
