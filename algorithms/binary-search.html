What is Binary Search?

Binary Search works on sorted data. It checks the middle value, then discards the half that cannot contain the target. This repeats until the target is found or the range is empty.

Color guide

Blue: values still in range. Purple: current midpoint. Faded: values ruled out.

Complexity

Best timeO(1)
Average timeO(log n)
Worst timeO(log n)
Extra spaceO(1)

How Binary Search works

Like finding a word in a dictionary, open near the middle, decide whether to look left or right, and repeat. Half the remaining values are discarded at each step.

  1. Set low and high boundaries.
  2. Calculate the middle index.
  3. If the middle value matches the target, return its index.
  4. If the target is larger, continue right; otherwise continue left.
  5. If low becomes greater than high, the target is absent.
Important: Binary Search requires sorted input. Its decisions are not reliable on an unsorted array.

Binary Search implementation in C

int binarySearch(const int arr[], int n, int target) {
    int low = 0, high = n - 1;
    while (low <= high) {
        int mid = low + (high - low) / 2;
        if (arr[mid] == target) return mid;
        if (arr[mid] < target) low = mid + 1;
        else high = mid - 1;
    }
    return -1;
}

The midpoint expression avoids potential overflow from adding low and high directly. The function returns an index if found and -1 otherwise.
