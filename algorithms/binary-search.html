What is Binary Search?

Binary Search works on sorted data. It checks the middle value, then discards the half that cannot contain the target. This repeats until the target is found or the range is empty.

How to read the colors

  • Blue: values still in the search range.
  • Purple: the current midpoint.
  • Faded: values ruled out.

UNDERSTAND THE ALGORITHM

How Binary Search works

Binary Search is like finding a word in a dictionary: open near the middle, decide whether to look left or right, and repeat. Because half the remaining values are discarded at each step, the number of checks grows slowly as the input gets larger.

  1. Set the low and high boundaries of the sorted array.
  2. Calculate the middle index.
  3. If the middle value equals the target, return its index.
  4. If the target is larger, continue on the right. Otherwise, continue on the left.
  5. If low becomes greater than high, the target is absent.
Important: Binary Search requires the input array to be sorted. On unsorted data, its decisions are not reliable.

Binary Search implementation in C

int binarySearch(const int arr[], int n, int target) {
    int low = 0;
    int high = n - 1;
    while (low <= high) {
        int mid = low + (high - low) / 2;
        if (arr[mid] == target) return mid;
        if (arr[mid] < target) low = mid + 1;
        else high = mid - 1;
    }
    return -1;
}

The expression low + (high - low) / 2 calculates the midpoint without the potential overflow of adding low and high directly. The function returns an index when the target is found and -1 otherwise.

When should you use Binary Search?

Use it when the data is sorted and supports efficient access by index, such as a sorted array. For linked lists or unsorted collections, other approaches may be more appropriate.
