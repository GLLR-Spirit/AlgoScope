What is Bubble Sort?

Bubble Sort repeatedly compares neighboring elements. If a pair is in the wrong order, it swaps them. After each pass, the largest remaining value has reached its final position.

How to read the colors

  • Blue: values not yet finalized.
  • Purple: the pair currently being compared.
  • Green: values placed in their final positions.

Complexity

Best time*O(n)
Average timeO(n²)
Worst timeO(n²)
Extra spaceO(1)

*The optimized version stops early if a pass makes no swaps.

UNDERSTAND THE ALGORITHM

How Bubble Sort works

Imagine moving through a row of numbers from left to right. Compare each pair of neighbors. When the left value is greater than the right value, exchange them. The largest value gradually moves toward the end, like a bubble rising to the surface.

  1. Start at the first pair of adjacent elements.
  2. Compare the two values and swap them if they are out of order.
  3. Continue to the end of the unsorted section.
  4. Repeat with a shorter section until the array is sorted.
Learning tip: press Next slowly and watch how each pass places one more large value at the end.

Bubble Sort implementation in C

void bubbleSort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int swapped = 0;
        for (int j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
                swapped = 1;
            }
        }
        if (!swapped) break;
    }
}

This optimized implementation uses a swapped flag to stop early if the array is already sorted. It modifies the array in place and needs only a constant amount of extra memory.

When should you use Bubble Sort?

Bubble Sort is useful for learning nested loops, comparisons, and sorting fundamentals. For large datasets, more efficient algorithms such as Merge Sort or Quick Sort are usually preferred.
