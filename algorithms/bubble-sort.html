What is Bubble Sort?

Bubble Sort repeatedly compares neighboring elements. If a pair is out of order, it swaps them. At the end of each pass, the largest remaining value reaches its final position.

Color guide

Blue: unsorted values. Purple: the pair being compared. Green: values in their final positions.

Complexity

Best time*O(n)
Average timeO(n²)
Worst timeO(n²)
Extra spaceO(1)

*With an early-stop optimization.

How Bubble Sort works

Compare each pair of neighboring numbers from left to right. If the left number is larger, swap the pair. Repeat with a shorter unsorted section until the array is ordered.

  1. Start with the first two elements.
  2. Compare them and swap if needed.
  3. Continue to the end of the unsorted section.
  4. Repeat until the array is sorted.
Learning tip: press Next slowly and watch one large value settle at the end on each pass.

Bubble Sort implementation in C

void bubbleSort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int swapped = 0;
        for (int j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
                swapped = 1;
            }
        }
        if (!swapped) break;
    }
}

The swapped flag stops early when a pass makes no exchanges. Bubble Sort is useful for learning loops and comparisons, but more efficient algorithms are preferred for large datasets.
